Kalshi referral code (2026): what it actually gives you

Kalshi's refer-a-friend program pays trading credits, not cash. The referred person signs up with a link or code, passes identity verification, and meets a trading requirement shown in the app; then both sides receive credits. Credits must be used within 7 days unless stated otherwise, only profits made with them become withdrawable, amounts and lifetime caps are set per account and shown in-app, and the program is US-only.
